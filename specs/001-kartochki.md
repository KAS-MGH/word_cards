# 001 — Двусторонние карточки

## Для кого и зачем
Для тех, кто учит иностранные слова (в том числе казахские). Нужно быстро добавлять слова и повторять их по карточкам с телефона или компьютера.

## Что должно быть
- Карточка имеет две стороны: слово (или фраза) и перевод/значение.
- По нажатию/тапу карточка переворачивается.
- Можно добавлять, редактировать и удалять карточки.
- Форма добавления: поле «Слово», поле «Перевод», кнопка «Добавить». Пустые поля не принимаются.
- Список карточек с кнопкой «Удалить» у каждой.
- Режим повторения: показывается одна сторона карточки (слово), по нажатию на карточку или кнопку «Показать» — вторая (перевод). Без анимации переворота.
- После показа перевода две кнопки: «Знаю» и «Не знаю». Затем следующая карточка.
- Карточки, отмеченные «Не знаю», показываются чаще (простой интервальный повтор: «Не знаю» — карточка возвращается в очередь скоро, «Знаю» — позже).
- Есть режим тренировки (показ карточек) и режим управления колодой (список карточек).
- Если карточек нет — подсказка «Добавьте первую карточку».
- Данные сохраняются в localStorage в формате JSON и остаются после перезагрузки страницы.
- Интерфейс на русском, подписи короткие.

## Примеры
- Добавить «hello» → «сәлем»: карточка появляется в списке.
- Повторение: видно «hello», нажатие показывает «сәлем», «Знаю» → следующая карточка.
- Перезагрузка страницы: карточки на месте.
- Удалить карточку: она исчезает из списка и из повторения.

## Ограничения
- Только HTML, CSS, JavaScript. Файлы: index.html, styles.css, script.js.
- Без библиотек, внешних ресурсов и отправки данных в интернет.
- Буквы ә, ғ, қ, ң, ө, ұ, ү, һ, і показываются без искажений (кодировка UTF-8).
- Кнопки и поля не меньше 44px; страница работает при ширине 375px.
- Без тёмной темы, статистики, экспорта/импорта, звуков и анимации переворота.
- Одна колода, без категорий и учётных записей.
