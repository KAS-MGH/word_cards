# 004 — Оценка карточек, система Лейтнера и итог сессии

## Для кого и зачем
Для тех, кто тренируется каждый день. Незнакомые слова должны возвращаться в ту же тренировку, пока не запомнятся; выученные — уходить на более высокие уровни и появляться реже. В конце тренировки нужен короткий итог и возможность отдельно повторить сложные слова.

## Что должно быть

### 1. Оценка карточки
- После показа перевода — кнопки «Знаю» и «Не знаю» (уже есть, поведение уточняется ниже).
- Каждый ответ записывается в историю карточки.

### 2. Система Лейтнера (уровни)
- У карточки есть уровень `box` от 0 до 5 и дата следующего повторения `nextReview` (день, формат `ГГГГ-ММ-ДД`, местное время).
- Интервалы по уровням: 0 — в этой же сессии, 1 — через 1 день, 2 — через 3 дня, 3 — через 7 дней, 4 — через 14 дней, 5 — через 30 дней.
- «Знаю» — уровень +1 (максимум 5), `nextReview` = сегодня + интервал нового уровня.
- «Не знаю» — уровень сбрасывается в 0, `nextReview` = сегодня.
- В тренировке показывается маленькая метка уровня («Уровень 2») там, где видно слово. В списке колоды — тоже, рядом с карточкой.

### 3. Сессия тренировки
- Сессия — это очередь карточек, у которых `nextReview` ≤ сегодня (с учётом выбранного тега и направления, как сейчас). Новые карточки и старые карточки без даты считаются «на сегодня».
- Порядок: сначала карточки с более ранней датой, при равенстве — с меньшим уровнем.
- «Не знаю»: карточка возвращается в очередь этой же сессии, примерно через 3 карточки (если очередь короче — в конец), и показывается снова, пока не будет отвечено «Знаю».
- Ответ «Знаю» на повторном показе в той же сессии выводит карточку из сессии с уровнем 1 и `nextReview` = завтра. Каждый ответ всё равно попадает в историю.
- Карточка, отвеченная «Знаю» с первого раза, выходит из сессии сразу.
- Сессия живёт только в памяти страницы. После перезагрузки она собирается заново из карточек, которые ещё должны повториться сегодня; уровни и даты уже сохранены.
- Если на сегодня повторять нечего — сообщение «На сегодня всё повторено» и кнопка «Тренировать всё равно» (берёт все карточки выбранной области, ответы работают как обычно).

### 4. Итог сессии
- Когда очередь пуста, вместо карточки показывается итог:
  - сколько карточек в сессии;
  - сколько ответов «Знаю» и «Не знаю» (всего ответов);
  - доля «Знаю» с первого раза, в процентах;
  - список сложных слов — тех, на которые в этой сессии хотя бы раз ответили «Не знаю» (слово и перевод).
- Кнопки: «Повторить сложные» (если они есть) и «Новая сессия».
- Итог не сохраняется и не копится в статистику: он нужен только сейчас.

### 5. Повтор сложных слов
- «Повторить сложные» запускает отдельную сессию только из сложных слов прошлой сессии.
- Правило возврата «Не знаю» такое же (карточка возвращается в очередь), но в этом режиме уровни и `nextReview` не меняются. Ответы пишутся в историю с пометкой `r: true`.
- В конце — такой же итог; сложными считаются слова, на которые снова ответили «Не знаю».
- В режиме повтора сверху есть подпись «Повтор сложных».

### Данные в localStorage
- Ключ остаётся `wordcards.v1`, формат JSON. Поля `box` и `due`, а также `data.step` остаются на месте, но `due` и `step` больше не определяют очередь (они не удаляются, чтобы данные не терялись).
- В карточку добавляются необязательные поля:
  - `nextReview` — строка `ГГГГ-ММ-ДД`;
  - `history` — массив ответов `{ "d": "ГГГГ-ММ-ДД", "ok": true|false, "r": true? }`, не более 50 последних;
  - `known`, `unknown` — общее число ответов «Знаю» / «Не знаю» (числа).
- Обратная совместимость (при загрузке, без потери данных):
  - нет `nextReview` → считается сегодняшним днём;
  - нет `history` → пустой массив; нет `known` / `unknown` → 0;
  - `box` вне диапазона 0–5 (старые карточки до 6) → приводится к 5; нет `box` → 0.
- Старые поля и карточки без новых полей открываются, редактируются и тренируются без ошибок. Новые поля записываются в localStorage только после первого ответа или сохранения.
- Настройки (`wordcards.settings.v1`) не меняются.

## Примеры
- Карточка «hello» уровня 0. «Знаю» с первого раза → уровень 1, `nextReview` — завтра, из сессии ушла.
- Карточка «game». «Не знаю» → уровень 0, через ~3 карточки появляется снова. «Знаю» → уровень 1, `nextReview` — завтра. В итоге «game» в списке сложных.
- У «run out of» уровень 3 и `nextReview` через 7 дней → сегодня в сессию не попадает.
- Сессия из 5 карточек: 7 ответов «Знаю», 2 «Не знаю», с первого раза «Знаю» у 3 из 5 → «60%». Сложных: 2.
- Старая колода из спецификации 001 (только `word`, `translation`, `box`, `due`) открывается, все карточки попадают в сегодняшнюю сессию.

## Ограничения
- Только HTML, CSS, JavaScript. Файлы: index.html, styles.css, script.js.
- Без библиотек, внешних ресурсов и отправки данных в интернет.
- Интерфейс на русском, подписи короткие. Примеры видны только со словом, на стороне перевода их нет.
- Казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) в сложных словах и итоге показываются без искажений.
- Кнопки не меньше 44px; страница работает при ширине 375px. Список сложных слов переносится по строкам и не ломает вёрстку.
- Без тёмной темы, экспорта/импорта, звуков, анимаций переворота и долгосрочной статистики (графики, серии дней, общая сводка). Итог сессии — единственный разрешённый экран с цифрами.
- Не меняются ключи localStorage; формат только расширяется необязательными полями.
- Работающие функции спецификаций 001–003 (теги, озвучка, поиск, направление, примеры) не ломаются.

- [ ] Метка уровня видна в тренировке на стороне со словом и в списке колоды.
- [ ] В сессию попадают только карточки с `nextReview` ≤ сегодня; остальные не показываются.
- [ ] «Не знаю» возвращает карточку в ту же сессию (через ~3 карточки), «Знаю» на повторе выводит её с уровнем 1 и датой «завтра».
- [ ] Если повторять нечего, видны «На сегодня всё повторено» и «Тренировать всё равно».

- [ ] Старые карточки (без новых полей, `box` до 6) открываются и тренируются без ошибок и без потери данных; ключ `wordcards.v1` не менялся.
