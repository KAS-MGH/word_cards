# 002 — Удобство ежедневной работы и примеры употребления

## Для кого и зачем
Для тех, кто пользуется карточками каждый день и накопил много слов. Нужно быстрее находить карточки, не терять их по случайному тапу и запоминать слово вместе с контекстом: в какой фразе оно используется.

## Что должно быть

### 1. Пример употребления (контекст)
- У карточки появляется необязательное поле «Пример» (предложение или фраза со словом).
- Поле есть в форме добавления и при редактировании. Можно оставить пустым.
- В списке колоды пример показывается под переводом более мелким серым текстом.
- В тренировке пример показывается на обороте карточки (вместе с переводом), под ним — подпись «Пример».
- Если примера нет, блок не показывается.
- Слово в примере выделяется жирным, если оно в нём встречается (без учёта регистра). Если не встречается — пример показывается как есть.

### 2. Поиск по колоде
- Над списком карточек — поле «Поиск».
- Список фильтруется по мере ввода: ищется в слове, переводе и примере, без учёта регистра.
- Если ничего не найдено — подсказка «Ничего не найдено».
- Кнопка «Сбросить» очищает поиск.
- Поиск не меняет сами карточки и не влияет на тренировку.

### 3. Направление тренировки
- В тренировке есть переключатель «Слово → перевод» / «Перевод → слово».
- При «Перевод → слово» на лицевой стороне показывается перевод, на обороте — слово и пример.
- Выбор запоминается после перезагрузки.
- Направление не влияет на очередь повторения и оценки «Знаю» / «Не знаю».

### 4. Защита от дублей
- При добавлении, если слово уже есть в колоде (без учёта регистра и лишних пробелов), карточка не добавляется. Показывается сообщение «Такая карточка уже есть».
- При редактировании так же нельзя сохранить слово, которое совпадает с другой карточкой.
- Одно слово с разными переводами допускается только как отдельная карточка с другим словом/написанием; совпадение проверяется по слову.

### 5. Подтверждение удаления
- Нажатие «Удалить» не удаляет сразу: кнопки в этой карточке меняются на «Удалить?» и «Отмена».
- Только второе нажатие «Удалить?» удаляет карточку. «Отмена» возвращает обычный вид.
- Без системных окон (`confirm`), подтверждение внутри страницы.

### Данные в localStorage
- В карточку добавляется необязательное поле `example` (строка). Остальные поля не меняются.
- Старые карточки без `example` работают как раньше: считаются карточками с пустым примером. Данные не теряются и не требуют переноса.
- Направление тренировки хранится отдельным ключом `wordcards.settings.v1` (JSON, например `{"reverse": false}`). Основной ключ `wordcards.v1` остаётся без других изменений.

## Примеры
- Добавить «run out of» → «закончиться», пример «We ran out of milk.» → в списке виден пример, слово выделено не будет (форма «ran» другая), в тренировке пример на обороте.
- Добавить «сәлем» → «привет», пример «Сәлем, қалың қалай?» → слово в примере выделено жирным.
- Ввести в поиске «mil» → остаются только карточки, где это есть в слове, переводе или примере.
- Добавить «Hello» при уже имеющемся «hello » → сообщение «Такая карточка уже есть».
- Нажать «Удалить», затем «Отмена» → карточка на месте. «Удалить» → «Удалить?» → карточка удалена.
- Включить «Перевод → слово», перезагрузить страницу → режим сохранился.

## Ограничения
- Только HTML, CSS, JavaScript. Файлы: index.html, styles.css, script.js.
- Без библиотек, внешних ресурсов и отправки данных в интернет.
- Казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) в словах, переводах, примерах и поиске показываются и находятся без искажений.
- Кнопки и поля не меньше 44px; страница работает при ширине 375px. Длинные примеры переносятся по строкам и не ломают вёрстку.
- Выделение слова в примере делается без `innerHTML` (текст не должен исполняться как разметка).
- Без тёмной темы, статистики, экспорта/импорта, звуков и анимации переворота.
- Не вводится несколько колод, теги и привязка повторения к датам — это отдельные спецификации.
- Работающие функции спецификации 001 не ломаются.

- [ ] Слово в примере выделяется жирным, если встречается; разметка из текста не исполняется (например, `<b>x</b>` показывается как обычный текст).
