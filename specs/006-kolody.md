# 006 — Колоды: несколько наборов слов

## Для кого и зачем
Для тех, кто учит несколько тем или языков сразу (например, «English», «Қазақша», «Работа»). Слова нужно держать в отдельных наборах — колодах, — выбирать, какую тренировать, и видеть, как идёт заучивание в каждой.

## Что должно быть

### 1. Колоды
- Колода — именованный набор карточек. Колод может быть несколько.
- Всегда есть хотя бы одна колода. Для старых данных создаётся колода «Основная», в неё попадают все существующие карточки.
- Создать колоду: поле «Название» и кнопка «Создать». Название — не пустое, не длиннее 30 символов, без повтора (регистр не важен). Лишние пробелы по краям убираются.
- Переименовать колоду (те же правила названия).
- Удалить колоду: сначала подтверждение с числом карточек («Удалить колоду и N карточек?»), как при удалении карточки. Последнюю оставшуюся колоду удалить нельзя.

### 2. Выбор колоды
- Сверху виден выбор колоды (список или кнопки). Выбранная колода — активная.
- Всё работает только внутри активной колоды: тренировка и её очередь, список карточек, поиск, теги, добавление новой карточки.
- Новая карточка всегда попадает в активную колоду.
- При смене колоды текущая сессия тренировки прерывается; новая собирается из активной колоды. Уровни и даты не меняются.
- Выбранная колода запоминается и после перезагрузки остаётся активной. Если сохранённой колоды уже нет — открывается первая.
- Теги остаются как были и работают внутри колоды (тег выбирается из тегов активной колоды).

### 3. Прогресс по колоде
- Для каждой колоды на экране выбора колод показано коротко:
  - «Выучено X из N» — выучено считается по карточкам с уровнем 4 и 5;
  - «На сегодня: K» — сколько карточек сейчас в очереди (`nextReview` ≤ сегодня).
- Рядом простая полоска заполнения X/N (без анимации). Пустая колода: «Пока пусто».
- Цифры пересчитываются из карточек при каждом показе, отдельно не хранятся.
- Это не статистика: без графиков, серий дней и общей сводки по всем колодам.

### Данные в localStorage
- Ключи `wordcards.v1` и `wordcards.settings.v1` остаются, формат JSON только расширяется необязательными полями:
  - в `data` — `decks`: массив `{ "id": строка, "name": строка }`;
  - в карточке — `deck`: id колоды;
  - в настройках — `activeDeck`: id колоды.
- Обратная совместимость (при загрузке, без потери данных):
  - нет `decks` → создаётся `[{ id: "main", name: "Основная" }]`;
  - у карточки нет `deck` или такой колоды нет → карточка относится к первой колоде;
  - нет `activeDeck` → активна первая колода.
- Старые поля карточек (`box`, `nextReview`, `history`, `known`, `unknown`, теги, примеры) не меняются.
- Новые поля записываются только после первого действия с колодами (создание, смена, добавление карточки).

## Примеры
- Старая колода из 12 карточек → после обновления страницы одна колода «Основная» с теми же 12 карточками, тренировка работает как раньше.
- Создать «Қазақша», выбрать её, добавить «сәлем» → «привет»: карточка видна только в «Қазақша», в «Основной» её нет.
- В «Основной» 10 карточек, у 4 уровень 4–5 → «Выучено 4 из 10»; у 3 дата повторения сегодня или раньше → «На сегодня: 3».
- Удалить «Қазақша» с 5 карточками → подтверждение «Удалить колоду и 5 карточек?»; после «да» колода исчезает, активной становится первая.
- Ввести название «основная» при существующей «Основная» → отказ с короткой подписью.
- Единственная колода: кнопка удаления недоступна или показывает подпись «Нужна хотя бы одна колода».

## Ограничения
- Только HTML, CSS, JavaScript. Файлы: index.html, styles.css, script.js. Без библиотек, внешних ресурсов и отправки данных в интернет.
- Интерфейс на русском, подписи короткие. Примеры видны только со словом, на стороне перевода их нет.
- Казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) в названиях колод показываются без искажений.
- Кнопки и поля не меньше 44px; страница работает при ширине 375px; длинные названия переносятся и не ломают вёрстку.
- Не делаем: перенос карточки между колодами, объединение колод, порядок колод, экспорт/импорт, тёмную тему, звуки, анимации, статистику.
- Работающие функции спецификаций 001–005 (теги, озвучка, поиск, направление, примеры, уровни Лейтнера, итог сессии, повтор сложных) не ломаются.
