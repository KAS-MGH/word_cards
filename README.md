# Карточки слов

Тренажёр с двусторонними карточками для запоминания иностранных слов. Работает в браузере на телефоне и компьютере, данные хранятся только в localStorage.

## Что умеет страница
- **Колода**: добавить карточку (слово, перевод, пример), изменить, удалить. Пустые слово и перевод не принимаются.
- **Пример**: необязательная фраза, где слово используется. Всегда идёт вместе со словом: в списке под словом, в тренировке на стороне со словом (на стороне перевода не показывается); само слово в примере выделяется жирным.
- **Поиск**: фильтрует колоду по слову, переводу и примеру; «Сбросить» очищает.
- **Дубли**: слово, которое уже есть (без учёта регистра и пробелов), добавить нельзя.
- **Удаление**: «Удалить» просит подтверждения («Удалить?» / «Отмена»).
- **Тренировка**: показывает слово; слово показывается вместе с примером, нажатие на карточку или «Показать» открывает перевод (уже без примера); затем «Знаю» / «Не знаю».
- **Направление**: кнопка вверху тренировки переключает «Слово → перевод» и «Перевод → слово»; выбор запоминается.
- «Не знаю» возвращает карточку скоро, «Знаю» — позже.
- Данные сохраняются после перезагрузки. Казахские буквы поддерживаются.

## Как проверить
1. Открыть index.html двойным щелчком.
2. «Колода»: добавить «сәлем» → «привет», пример «Сәлем, қалың қалай?» — слово в примере станет жирным.
3. Добавить «Сәлем» ещё раз — «Такая карточка уже есть».
4. Ввести в поиске «қал» — останутся карточки с этим текстом; «Сбросить» вернёт все.
5. «Удалить» → «Отмена» — карточка на месте; «Удалить» → «Удалить?» — карточка удалена.
6. «Тренировка»: слово и пример видны вместе; нажать на карточку — виден перевод, примера на этой стороне нет. Переключить направление, перезагрузить страницу — режим сохранился.
7. Сузить окно до 375px — всё помещается.
