# Карточки слов

Тренажёр с двусторонними карточками для запоминания иностранных слов. Работает в браузере на телефоне и компьютере, данные хранятся только в localStorage.

## Что умеет страница
- **Колода**: добавить карточку (слово + перевод), изменить, удалить. Пустые поля не принимаются.
- **Тренировка**: показывает слово; нажатие на карточку или «Показать» открывает перевод; затем «Знаю» / «Не знаю».
- «Не знаю» возвращает карточку скоро, «Знаю» — позже (чем чаще «Знаю», тем реже карточка).
- Данные сохраняются после перезагрузки. Казахские буквы поддерживаются.

## Как проверить
1. Открыть index.html двойным щелчком.
2. Вкладка «Колода»: добавить «hello» → «сәлем» и ещё пару карточек; изменить и удалить одну.
3. Вкладка «Тренировка»: нажать на карточку, ответить «Знаю» и «Не знаю»; карточка с «Не знаю» вернётся раньше.
4. Перезагрузить страницу — карточки на месте.
5. Сузить окно до 375px — всё помещается.
