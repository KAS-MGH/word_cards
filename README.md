# Карточки слов

Тренажёр с двусторонними карточками для запоминания иностранных слов. Работает в браузере на телефоне и компьютере. Данные хранятся только в localStorage, в интернет ничего не отправляется. Файлы: `index.html` (разметка), `styles.css` (вид), `script.js` (логика), `dict.js` (мини-словарь транскрипций).

## Что умеет

### 1. Двусторонние карточки — [specs/001-kartochki.md](specs/001-kartochki.md)
- Добавить, изменить и удалить карточку (слово + перевод). Пустые поля не принимаются.
- Тренировка: показано слово, по нажатию на карточку или «Показать» открывается перевод, затем «Знаю» / «Не знаю». «Не знаю» возвращает карточку скоро, «Знаю» — позже.
- Режимы «Тренировка» и «Колода». Данные сохраняются после перезагрузки.

### 2. Удобство и примеры — [specs/002-udobstvo-i-primery.md](specs/002-udobstvo-i-primery.md)
- Пример употребления: показывается только вместе со словом (на стороне перевода его нет), слово в примере выделяется жирным.
- Поиск по колоде (слово, перевод, пример), кнопка «Сбросить».
- Направление тренировки «Слово → перевод» / «Перевод → слово» (запоминается).
- Защита от дублей («Такая карточка уже есть») и подтверждение удаления («Удалить?» / «Отмена»).

### 3. Наполнение карточки — [specs/003-napolnenie-kartochki.md](specs/003-napolnenie-kartochki.md)
- Озвучка слова кнопкой «🔊 Слушать» (голос браузера, без интернета). Если голоса нет — сообщение «Нет голоса для этого языка или слова» над словом.
- Язык слова, транскрипция (для английских слов из `dict.js` — варианты US / UK / AU), часть речи, личная заметка.
- Теги-тематики через запятую, фильтр по тегу в колоде и в тренировке, поиск по заметке и тегам.
- В колоде: сверху слово, язык, транскрипция, часть речи; ниже слева перевод, справа пример и заметка; ещё ниже теги.

### 4. Оценка и система Лейтнера — [specs/004-ocenka-i-leitner.md](specs/004-ocenka-i-leitner.md)
- Уровни 0–5 (метка «Уровень N» в тренировке и в колоде). «Знаю» — уровень +1 и `nextReview` через 1 / 3 / 7 / 14 / 30 дней; «Не знаю» — уровень 0, повтор сегодня. Каждый ответ пишется в `history` (последние 50), растут `known` / `unknown`.
- В сессию попадают карточки с `nextReview` ≤ сегодня. «Не знаю» возвращает карточку в ту же сессию через ~3 карточки; «Знаю» на повторе — уровень 1 и «завтра». Если повторять нечего — «На сегодня всё повторено» и «Тренировать всё равно».
- Итог сессии (не сохраняется): число карточек, «Знаю» / «Не знаю», доля «с первого раза», список сложных слов.
- «Повторить сложные» — отдельная сессия из сложных слов с подписью «Повтор сложных». Уровни и `nextReview` не меняются, ответы пишутся в `history` с `r: true`.
- Старые карточки (без новых полей, `box` до 6) открываются без потери данных; ключ `wordcards.v1` не менялся.

### 5. Колоды — [specs/006-kolody.md](specs/006-kolody.md)
- Несколько наборов слов. Вкладка «Колоды»: создать (до 30 символов, без повтора), переименовать, удалить (с подтверждением и числом карточек; последнюю удалить нельзя). Выбор колоды сверху; тренировка, список, поиск, теги и добавление работают только в активной колоде, выбор запоминается.
- У каждой колоды: «Выучено X из N» (уровни 4–5), «На сегодня: K» (`nextReview` ≤ сегодня) и полоска X/N; у пустой — «Пока пусто». Цифры считаются при каждом показе.
- Старые данные открываются как колода «Основная»; ключи `wordcards.v1` и `wordcards.settings.v1` прежние.

Казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) поддерживаются везде.

## Как открыть и проверить
Открыть `index.html` двойным щелчком. Дальше — проверка по числам (в скобках ожидаемый результат):

1. Вкладки: 2 («Тренировка», «Колода»).
2. «Колода»: добавить 3 карточки — «hello» → «привет», «game» → «игра», «сәлем» → «привет» (в списке **3** карточки; после перезагрузки страницы тоже **3**).
3. Добавить «Hello » с пробелом (**«Такая карточка уже есть»**, карточек по-прежнему **3**).
4. Поиск «mil» при примере «We ran out of milk.» у одной карточки (остаётся **1** карточка); «Сбросить» (снова **3**).
5. Транскрипция, язык English: «game» → **3** кнопки (US, UK, AU); «hello» → **3**; «hi» → **1** кнопка без метки; слово вне словаря (например «zebra») → **0** кнопок, ввод вручную работает. В словаре сейчас **153** слова.
6. Теги: «Еда, еда , ЕДА» → **1** тег «еда»; 7 разных тегов → сохраняются **5**; тег из 25 символов → обрезается до **20**.
7. Фильтр по тегу «еда»: в списке и в тренировке только карточки с этим тегом; после перезагрузки выбор сохранён; удалить последнюю такую карточку — фильтр возвращается на «Все».
8. Озвучка: нажать «🔊» **3** раза подряд — «game», «hello», снова «game» — слово слышно **3** раза из **3**. В тренировке нажатие «🔊» карточку не переворачивает.
9. Тренировка: **2** стороны карточки; на стороне перевода нет примера, транскрипции, части речи и заметки (**0** штук); после «Знаю» / «Не знаю» показывается следующая карточка.
10. Ширина окна **375px**: нет горизонтальной прокрутки, все кнопки и поля высотой не меньше **44px**.
11. Лейтнер: «Знаю» с первого раза → «Уровень 1», `nextReview` — завтра, карточка ушла из сессии. «Не знаю» → уровень 0, карточка вернулась через ~3 других.
12. Итог: после последней карточки — числа и список сложных слов (только те, где был «Не знаю»). «Повторить сложные» → подпись «Повтор сложных», только сложные слова; в localStorage `box` и `nextReview` те же, в `history` новые записи с `r: true`.
13. Колоды: вкладка «Колоды», в «Основной» 10 карточек, у 4 уровень 4–5 → **«Выучено 4 из 10»**, полоска на 40%; у 3 дата сегодня или раньше → **«На сегодня: 3»**. «Знаю» на карточку очереди → «На сегодня: 2». Новая пустая колода → **«Пока пусто»**. На **375px** ничего не вылезает.

## Правила для агента
Правила работы с проектом лежат в [AGENTS.md](AGENTS.md): только HTML/CSS/JS без внешних ресурсов, спека `specs/NNN-*.md` до кода, код только после слова «делай», отметки [Х] только для проверенного, коммит после тестов.

**Правило, добавленное после ошибки.** После первой версии примеров в AGENTS.md появилось правило про слова с примерами. Ошибка: пример показывался под переводом и на обороте карточки, поэтому он визуально отрывался от своего слова и путался с соседними карточками. Первая формулировка была такой: «Слова с примерами должны всегда идти вместе и не путаться с другими словами».

## Отчёт

**Сработало сразу**
- «Пока я не написал „делай“, код не пиши»: спека 003 была написана и показана, код — только после «делай».
- «Ничего не отправляй в интернет»: онлайн-словарь для транскрипции не подключали, сделали встроенный `dict.js`.
- «Не добавлять звуки, пока не попросят»: озвучка добавлена только после явной просьбы.

**Не сработало сразу**
- Правило про слова с примерами в первой формулировке было слишком общим: «идти вместе» и «не путаться» можно было выполнить, оставив пример на обороте рядом с переводом. Правило не запрещало показывать пример рядом с переводом, поэтому ошибка осталась.
- Правило про три файла («index.html, styles.css, script.js») не учло файл словаря: `dict.js` пришлось добавить как исключение в спеке 003; в AGENTS.md строка про файлы обновлена.

**Как переписано.** Правило про примеры стало конкретным и проверяемым: «Слова с примерами не раздельны, примеры отображаются только со словами, в части перевода примеров не видно» (коммит «уточнить правило отображения примера»). Вслед за ним поправили спеку 002 и код: пример показывается только на стороне со словом.

**Что осталось непроверенным (спека 003)**
- Озвучка при повторных нажатиях («game» → другое слово → «game») и на казахском: зависит от голосов в системе, проверять нужно на устройстве пользователя.
- Вид на 375px и расположение полей в браузере.
